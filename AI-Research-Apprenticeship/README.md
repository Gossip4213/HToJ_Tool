# AI Research Apprenticeship

版本：1.0 · 建档：2026-10-11 · 首课计划：2026-10-12

以可复现的项目交付培养大模型原理、后训练、智能体工程和研究评估能力。长期目标是一个能积累共同经历、持续适应、保留稳定风格与判断能力的个人 AI 秘书。

## 已约定的培养契约

项目顺序：P01 MiniGPT → P02 Persona-LoRA → P03 Agent Workbench → P04 Alignment Lab → P05 Long-Term Memory → P06 Personal AI。

每项通常 35–50 天；提前达到相同验收门槛可加速。2027 年春招前优先前三项，求职开始后可调整学习负荷。能力理解优先，同时逐步引入可复现、测试、版本控制、配置、日志与文档等工程要求。

评分：理论 20、工程 20、实验 25、独立解决问题 20、文档展示 15。80 分起良好，90 分起优秀；重大缺陷必须返工。

导师负责解释、布置任务、审查、答辩与基于证据的评价。学生需要理解关键代码、独立完成迁移题，并区分自己完成和 AI 辅助的部分。

## 使用方式

每次开始课程先读进度、最近日志和相关项目任务；每次结束记录具体证据与下一步。计划、模板、已创建文件均不算已经掌握的能力。

当前档案位于 Gossip4213/HToJ_Tool 的 ai-research-apprenticeship 分支下。这里暂时承载教学管理文件；具体项目预期各自形成独立 GitHub 仓库。当前连接未提供新建仓库操作，迁移时保留本目录和提交历史索引。

课程本身不保证特定学历等效、论文录用或录用结果。工程能力与研究能力分别依据成果评估；研究目标需要持续积累。
